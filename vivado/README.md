# Vivado Reconstruction Inputs

This directory contains source inputs only. It excludes generated projects, runs, caches, output products, DCP, LTX, logs, and machine databases.

Set PROTECTION_IP_VIVADO_BUILD_ROOT to an external empty directory and follow ../docs/vivado_build_guide.md. The Tcl files are public path-parameterized projections of the tracked development inputs. No Tcl or constraint source in the engineering repository was modified.
