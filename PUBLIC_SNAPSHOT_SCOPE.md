# Public Snapshot Scope

## Role

This repository is a stable local public snapshot for project demonstration, source review, simulation reproduction, Vivado reconstruction, and PYNQ-Z2 deployment. The engineering repository remains the sole development authority.

## Included Categories

- Stable tracked RTL and register definitions.
- Ten canonical testbenches and the Icarus runner.
- Portable Vivado project, packaging, block-design, controlled-stimulus, debug, and constraint inputs.
- Non-duplicated PYNQ interface source and host-side tests.
- The complete verified 22-file deployment release under deploy.
- Public technical documents, provenance, inventories, and verification summaries.

## Excluded Categories

- Generated Vivado runs, workspaces, caches, DCP, LTX, logs, and databases.
- Historical and accepted evidence archives, computer audits, inventories, and handoff packages.
- PYNQ operating-system images, third-party manuals, internal reports, presentations, and credentials.
- Temporary simulation output, duplicate BIT/HWH files, and duplicate snapshot archives.

## Assets

NO_SUITABLE_PUBLIC_ASSET_SELECTED. No existing image was both necessary for this snapshot and preferable to the source-backed textual architecture description, so docs/assets was not created.

## Duplicate Policy

No non-empty exact duplicate group is accepted. Deploy is the only deployment runtime and BIT/HWH authority. PYNQ source outside deploy is included only when its bytes differ and it serves source-level understanding or tests.

## Deferred Governance Files

LICENSE, CHANGELOG.md, CONTRIBUTING.md, CITATION.cff, and SECURITY.md are intentionally absent. These files are deferred for a later public-governance step. Their absence does not grant permission to use, redistribute, or modify the material.
